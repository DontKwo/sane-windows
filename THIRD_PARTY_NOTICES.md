# Third-Party Notices and Provenance

## Proprietary Binaries
This repository contains no third-party proprietary binaries (e.g., Sysinternals, NirSoft).
Any tools referenced or utilized in this repository are managed by the user's environment or installed via their official sources.

## Dynamic Dependencies
The script `check-tooling.ps1` dynamically fetches and installs the following developer tools from their official sources:
- `git`
- `uv`
- `python`
- `pnpm`
- `npm`
- `cargo`
- `docker`
- `wsl`

These tools are not bundled with this repository and are subject to their respective licenses when downloaded and installed on the user's machine.

## Open Source Utilities
Any open-source components used or referenced are attributed to their respective owners. No GPL-incompatible proprietary software is bundled.
